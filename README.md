# twdashboard

台指期風控儀表盤：輸入帳戶餘額、部位與現價，即時試算權益數、風險指標、保證金、距追繳／代沖銷點數與情境壓力測試。

- 線上使用：https://twdashboard.github.io/
- 支援契約：大台 TX（每點 200 元）、小台 MTX（每點 50 元）、微台 TMF（每點 10 元）
- 純靜態 HTML/CSS/JS（ES modules），零外部相依、不用 CDN、不需建置

## 功能

- KPI：權益數、未實現損益、風險指標、原始／維持保證金、超額保證金、距追繳點數、距代沖銷點數、淨部位換算大台口數、淨槓桿／總槓桿
- 持倉表：行內修改現價、平倉（dialog）、刪除；可一鍵套用同一現價
- 情境壓力測試：指數 ±1%／3%／5%／7%／10%（10% 為漲跌停）
- 權益曲線（手寫 SVG）、最大回撤與目前回撤（需每日手動「記錄權益」）
- 平倉紀錄
- 設定：保證金、手續費、期交稅率、代沖銷門檻、還原預設
- JSON 匯出／匯入備份
- 深淺色主題自動跟隨系統；支援手機版排版

## 使用方式

本工具為純手動試算，不連接券商，所有數字都由你輸入。建議流程：

1. 填入帳戶餘額（不含未實現損益）。
2. 新增部位（契約、方向、口數、成本價、現價）。
3. 盤中或收盤後更新現價（可行內修改，或一鍵套用現價）。
4. 每日收盤後按「記錄權益」，權益曲線與回撤才會有資料。
5. 定期匯出 JSON 備份（清除瀏覽器資料會一併清掉紀錄）。

## 計算方式

| 項目 | 規則 |
| --- | --- |
| 權益數 | 帳戶餘額 + 未實現損益 |
| 未實現損益 | (現價 − 成本價) × 方向 × 口數 × 乘數 |
| 風險指標 | 權益數 ÷ 原始保證金 |
| 追繳 | 權益數 < 維持保證金 |
| 代沖銷 | 風險指標 ≤ 25%（門檻可於設定調整） |
| 距門檻點數 | (門檻 − 權益數) ÷ 每點損益；門檻為維持保證金或原始保證金 × 代沖銷比例 |
| 壓力測試 | 指數同步漲跌指定百分比重算權益；保證金不隨價格變動 |
| 平倉成本 | 只扣平倉邊的手續費 + 期交稅（契約金額 × 十萬分之 2，四捨五入至元） |

保證金預設值取自[期交所保證金一覽表](https://www.taifex.com.tw/cht/5/indexMarging)（2026/08/12 更新）：

| 契約 | 原始保證金 | 維持保證金 |
| --- | ---: | ---: |
| TX | 701,000 | 538,000 |
| MTX | 175,250 | 134,500 |
| TMF | 35,050 | 26,900 |

期交所會不定期調整，請至設定自行修改。

## 已知限制與免責聲明

- 不計跨月價差保證金減收，持有價差部位時保證金會被高估（偏保守）。
- 建倉手續費不扣，視為已反映在帳戶餘額。
- 期貨商可能收取高於期交所的保證金，風險指標的算法也可能不同；實際追繳與代沖銷以你的期貨商為準。
- 保證金預設值可能落後於期交所最新公告。
- 顏色採台股慣例紅漲綠跌，另以 +／− 號與文字標示，不只靠顏色。
- 本工具僅為試算輔助，不構成投資建議；使用者須自行承擔交易與依賴試算結果的風險。

## 隱私

資料只存在你瀏覽器的 localStorage（key：`twdashboard.state.v1`），不會上傳，也沒有任何對外請求（CSP 的 `connect-src 'none'`）。換裝置或瀏覽器請用 JSON 匯出／匯入。

## 本機開發與測試

```bash
python3 -m http.server      # 然後開 http://localhost:8000
node --test 'tests/**/*.test.mjs'
```

- 不可用 `file://` 開啟，ES modules 會被 CORS 擋住。
- 測試使用 Node 內建 test runner（CI 用 Node 22）；`node --test tests/` 在 Node 22 無法執行，請用上述 glob 寫法。
- 目前 104 個案例。`app.js`、`chart.js` 涉及 DOM，沒有自動化測試，以 headless Chromium 手動 smoke test 驗證。
- 慣例與架構細節見 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)，變更紀錄見 [docs/CHANGELOG.md](docs/CHANGELOG.md)。

## 專案結構

```

tests/*.test.mjs      contracts／risk／store 單元測試

docs/                 DEVELOPMENT.md、CHANGELOG.md
```
